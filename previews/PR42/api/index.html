API

Featured functions and macros

LazyBroadcast defines two exported functions:

  • lazy_broadcast - the main feature of LazyBroadcast, which turns broadcast expressions into lazy broadcasted objects.
  • @lazy_broadcast - which allows users to call lazy_broadcast without parenthesis.

and two un-exported functions (un-exported intentionally to avoid name collisions)

  • lazy - an alias of lazy_broadcast
  • @lazy - an alias of @lazy_broadcast

It also defines these un-exported names:

  • NullBroadcasted - a broadcast object that vanishes from sums and makes products vanish.
  • fused_direct, fused_assemble, @make_type, @make_fused and @make_get_fused - tools for fusing several broadcast expressions into one loop.

lazy_broadcast

LazyBroadcast.lazy_broadcast — Function
function lazy_broadcast end # exported
const lazy = lazy_broadcast # not exported

This function has no methods and is only meant to be used to consume a broadcast expression, causing it to not materialize, allowing it to be used in a lazy manner and be consumed later.

For example, consider the situation where one wants to break up a complicated broadcast expression into multiple steps, and then sum up all of the components:

julia> using BenchmarkTools

julia> function foo(x)
           y = x .+ x
           z = 2 .* y
           sum(z)
       end;

julia> @btime foo(v) setup=(v=rand(10))
  43.096 ns (2 allocations: 288 bytes)
20.37839658590829

This is significantly slower than it needs to be because new arrays need to be allocated for y and z, and the data needs to be passed over multiple times because the broadcast kernels are not 'fused'.

lazy_broadcast gives a simple way to avoid these allocations and retain broadcast fusion:

julia> using BenchmarkTools, LazyBroadcast

julia> function foo_lazy(x)
           y = lazy_broadcast.(x .+ x)
           z = lazy_broadcast.(2 .* y)
           sum(z)
       end;

julia> @btime foo_lazy(v) setup=(v=rand(10))
  5.958 ns (0 allocations: 0 bytes)
23.002907370961225

the result of a lazy_broadcast call can be collected into an array with the materialize function (re-exported here from Base.Broadcast):

julia> lazy_broadcast.(2 .* [1,2,3])
Broadcasted{Base.Broadcast.DefaultArrayStyle{1}}(*, (2, [1, 2, 3]))

julia> materialize(ans)
3-element Vector{Int64}:
 2
 4
 6

NullBroadcasted

LazyBroadcast.NullBroadcasted — Type
NullBroadcasted()

A Base.AbstractBroadcasted that represents arithmetic object.

An NullBroadcasted() can be added to, subtracted from, or multiplied by any value in a broadcast expression without incurring a runtime performance penalty.

For example, the following rules hold when broadcasting instances of NullBroadcasted:

1 + NullBroadcasted() == 1 NullBroadcasted() + 1 == 1 1 - NullBroadcasted() == 1 1 * NullBroadcasted() == NullBroadcasted() 1 / NullBroadcasted() == NullBroadcasted()

Broadcast fusion

LazyBroadcast.fused_direct — Function
fused_direct(expr::Expr)

Directly transforms the input expression into a tuple of Pairs, containing (firsts) the destination of broadcast expressions and (seconds) the broadcasted objects.

For example:

import LazyBroadcast as LB
using Test
expr_in = quote
    @. y1 = x1 + x2 + x3 + x4
    @. y2 = x2 + x3 + x4 + x5
end

expr_out = :(tuple(
    Pair(y1, Base.broadcasted(+, x1, x2, x3, x4)),
    Pair(y2, Base.broadcasted(+, x2, x3, x4, x5)),
))
@test LB.fused_direct(expr_in) == expr_out

This can be used to make a custom kernel fusion macro:

import LazyBroadcast: @make_type, @make_fused, fused_direct
@make_type MyFusedBroadcast
@make_fused fused_direct MyFusedBroadcast my_fused

Base.copyto!(fmb::MyFusedBroadcast) = println("You're ready to fuse!")

x1 = rand(3,3)
y1 = rand(3,3)
y2 = rand(3,3)

# 4 reads, 2 writes
@my_fused begin
  @. y1 = x1
  @. y2 = x1
end

LazyBroadcast.fused_assemble — Function
fused_assemble(expr::Expr)

Transforms the input expressions into a runtime assembly of a tuple of Pairs, containing (firsts) the destination of broadcast expressions and (seconds) the broadcasted objects.

For example:

import LazyBroadcast as LB
using Test
expr_in = quote
    @. y1 = x1 + x2 + x3 + x4
    @. y2 = x2 + x3 + x4 + x5
end

expr_out = quote
    tup = ()
    tup = (tup..., Pair(y1, Base.broadcasted(+, x1, x2, x3, x4)))
    tup = (tup..., Pair(y2, Base.broadcasted(+, x2, x3, x4, x5)))
    tup
end

@test LB.linefilter!(LB.fused_assemble(expr_in, :tup)) ==
      LB.linefilter!(expr_out)
@test LB.fused_assemble(expr_in, :tup) == expr_out

This can be used to make a custom kernel fusion macro:

import LazyBroadcast: @make_type, @make_fused, fused_assemble
@make_type MyFusedBroadcast
@make_fused fused_assemble MyFusedBroadcast my_fused

Base.copyto!(fmb::MyFusedBroadcast) = println("You're ready to fuse!")

x1 = rand(3,3)
y1 = rand(3,3)
y2 = rand(3,3)

# 4 reads, 2 writes
@my_fused begin
    for i in 1:3
        @. y1 = x1
        @. y2 = x1
    end
end

LazyBroadcast.@make_fused — Macro
@make_fused fusion_style type_name fused_named

This macro

  • Defines a type type_name
  • Defines a macro, @fused_name, using the fusion type fusion_style

This allows users to flexibility to customize their broadcast fusion.

Example

import LazyBroadcast: @make_type, @make_fused, fused_direct
@make_type MyFusedBroadcast
@make_fused fused_direct MyFusedBroadcast my_fused

Base.copyto!(fmb::MyFusedBroadcast) = println("You're ready to fuse!")

x1 = rand(3,3)
y1 = rand(3,3)
y2 = rand(3,3)

# 4 reads, 2 writes
@my_fused begin
  @. y1 = x1

LazyBroadcast.@make_get_fused — Macro
@make_get_fused fusion_style type_name fused_named

This macro

  • Defines a type type_name
  • Defines a macro, @fused_name, using the fusion type fusion_style

This allows users to flexibility to customize their broadcast fusion.

Example

import LazyBroadcast: @make_type, @make_get_fused, fused_direct
@make_type MyFusedBroadcast
@make_get_fused fused_direct MyFusedBroadcast get_fused

x1 = rand(3,3)
y1 = rand(3,3)
y2 = rand(3,3)

# 4 reads, 2 writes
fmb = @get_fused begin
  @. y1 = x1
  @. y2 = x1
end
@test fmb isa MyFusedBroadcast
